ANALYST PRACTICE / ACCESS REVOCATION

A valid login does not guarantee permission

A group member is removed. The same session still verifies, and the next private-data request is made. What would each response mean?

Try explaining it first, then reveal the interpretation
  • 403 with the expected denial body: supports enforcement on that path, when the known-record positive control also passes.
  • 200 with the known private record: the expected boundary failed; investigate membership timing, source version and any deliberate lab fault.
  • 503: a service failure. It cannot count as successful authorization enforcement.
  • 200 with no visible rows: can be normal row filtering. It needs a known existing record and positive controls; the HTTP status alone is insufficient.

Write your conclusion in four parts: observation, interpretation, uncertainty, next check. These examples are training prompts, not new findings.
