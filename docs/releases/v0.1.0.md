The first tagged release of SignalBridge, an access-assurance and detection lab. It watches real
authorization paths in two synthetic business apps, detects when someone keeps access they
should have lost, and takes an analyst from the finding to an independently verified fix.

## What it includes

- **The console:** signed, schema-checked ingestion, five versioned detection rules (R1–R5), and
  scoped analyst cases with independent review.
- **Lab integrations, each recorded with a receipt:** Keycloak sign-in with MFA, Wazuh, OWASP
  ZAP, a Shuffle workflow, Prometheus and Grafana, and signed leaver events from AccessOps.
- **Detection rules as code:** Sigma rules with MITRE ATT&CK tags, plus Splunk SPL and KQL, all
  checked against the same 48 frozen scenarios.
- **A blind-evaluation kit** for scenarios written by an external author. No blind round has been
  run yet.

## Results at this release

Each result links its receipt in [`docs/EVIDENCE.md`](https://github.com/aman-agarwal6/signalbridge/blob/main/docs/EVIDENCE.md).

| Check | Result |
| --- | --- |
| PostgreSQL concurrency and crash recovery | 14 of 14 checks |
| Keycloak sign-in (password and TOTP) | 28 protocol controls and 5 real-browser checks |
| Wazuh | 8 of 8 alerts raised exactly once |
| Detection on 48 builder-written scenarios | precision 15/21, recall 15/23, false-positive rate 6/18 |
| Detection rules in other engines | KQL in Microsoft's Kusto emulator matched the Python rules in 48 of 48 scenarios; hand-written SPL in Splunk Free in 45 |

## Limits

- Synthetic data in an isolated lab on one PC. This is not a production deployment.
- The detection scenarios were written by the rules' author: regression evidence, not independent
  accuracy.
- The full 24-hour run was not completed.

## Verify this release

The archive is built from this tag's commit by GitHub Actions, after the core and Sigma checks
passed on that same commit. It is signed with Sigstore build provenance. The SBOM is GitHub's
dependency graph for that commit.

```bash
gh release download v0.1.0 --repo aman-agarwal6/signalbridge
sha256sum -c SHA256SUMS
gh attestation verify signalbridge-v0.1.0.tar.gz --repo aman-agarwal6/signalbridge
```

Built under Aman Agarwal's project direction, with AI coding agents writing much of the
implementation.
